========================================
  CARA GANTI GAMBAR GAME (SUPER CEPAT)
========================================

STRUKTUR FOLDER:
GameStoreID-Pro/
├── index.html
├── style.css
├── script.js
└── assets/
    └── games/          ← TARUH GAMBAR DI SINI
        ├── mobile-legends.svg   (atau .jpg / .png / .webp)
        ├── roblox.svg
        ├── free-fire.svg
        └── ... dst

----------------------------------------
LANGKAH 1 — Siapkan gambar
----------------------------------------
- Ukuran ideal : 800 x 400 pixel (atau 400 x 200)
- Format       : .jpg  .png  .webp  (boleh juga .svg)
- Nama file    : samakan dengan yang ada di folder assets/games/

Contoh nama file yang sudah dipakai:
  mobile-legends.jpg
  roblox.png
  free-fire.webp
  pubg-mobile.jpg
  genshin-impact.jpg
  valorant.jpg
  honkai-star-rail.jpg
  call-of-duty-mobile.jpg
  arena-of-valor.jpg
  minecraft.jpg
  wild-rift.jpg
  zenless-zone-zero.jpg

----------------------------------------
LANGKAH 2 — Ganti file di folder
----------------------------------------
1. Buka folder:  assets/games/
2. Hapus file lama (contoh: mobile-legends.svg)
3. Masukkan gambar barumu dengan NAMA YANG SAMA
   (contoh: mobile-legends.jpg)

----------------------------------------
LANGKAH 3 — Ubah path di script.js (PENTING)
----------------------------------------
Buka file script.js, cari bagian:

const games = [
    { id:1, name:"Mobile Legends", ..., image:"assets/games/mobile-legends.svg", ... },
    { id:2, name:"Roblox",         ..., image:"assets/games/roblox.svg", ... },
    ...
];

Ganti ekstensi sesuai file barumu:

  image:"assets/games/mobile-legends.jpg"
  image:"assets/games/roblox.png"
  image:"assets/games/free-fire.webp"

Simpan → refresh browser. Selesai!

----------------------------------------
TIPS CEPAT
----------------------------------------
• Kalau nama file sama persis, cukup ganti ekstensi di script.js
• Kalau mau pakai nama beda, ubah juga path-nya di script.js
• Gambar online juga bisa, contoh:
  image:"https://contoh.com/gambar-ml.jpg"
• Setelah ganti, tekan Ctrl+F5 di browser biar cache hilang
